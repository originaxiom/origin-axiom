--------------------------------------------------------------------------

   RIGHT-handed trefoil.  So the Habiro expansion above is 3^r_1, and GM (page 73)

   LOWEST power of q in the coefficient of x^{m/2} has exponent of order c m^2.
   c > 0 means the blocks run UP; c < 0 (the figure-eight, c = -1/16) means DOWN.
