# B1000 — PREREGISTRATION: does the external-input count close on the four incompletenesses?

**SEALED BEFORE COMPUTE. 2026-08-09.** Nothing below written after seeing a result.

## P0 — the quantifier

Computes over **the corpus's own claims about what the object does not supply**. Not a manifold,
not a census — a **reconciliation of three existing counts**. This tests the framework against its
**own doctrine**, not against physics.

## The question

Three incompatible counts of the external inputs exist and **no arc reconciles them**:

| source | count |
|---|---|
| **B717** | **4** — the object's incompletenesses (space, time, charge, value); *"the observer supplies every closing"* |
| **B300** | **8** — *"the eight external inputs compress to two walls"* |
| **sweep (2026-08-09)** | **~8** — chirality, the 27-VEV, the anchor, the N=2→N=1 datum, the 6d type, the filling slope, P5 completeness, time |

**The doctrine's implicit prediction:** if the observer closes exactly the object's incompletenesses,
then **the irreducible external input count is 4**, and every additional import is an artifact of the
particular bridge, not of the object.

## The method — fixed here

1. **Enumerate** every distinct external input the corpus names, by sweep over `arc_verdict.json`
   claim lines, on the phrases already used: *external input · externally supplied · not
   self-supplied · inserted closing · free input · an import · does not supply · cannot close
   itself*. Every hit is listed with its arc; **nothing is dropped silently**.
2. **Deduplicate by referent**, not by phrasing — two arcs naming the same missing thing count once.
   Each merge is recorded with both arcs.
3. **Classify** each surviving input as either
   **(a) a CLOSING of one of B717's four** — space, time, charge, value — or
   **(b) a BRIDGE ARTIFACT**: a modelling choice of the particular route to physics, not a property
   of the object.
4. **Count (a).** The classification of each is written **before** the total is taken.

## The two outcomes

- **OUTCOME A — the closings are exactly 4, one per incompleteness.** The observer-coupling doctrine
  becomes **quantitative**: the object's deficits and the chain's imports are the same list. Every
  remaining import is then a **bridge artifact and therefore reducible**, and each becomes a named
  debt.
- **OUTCOME B — the closings are NOT 4.** Either **>4** (B717 under-counts and the doctrine needs a
  fifth incompleteness — a real correction to the capstone), or **<4** (one incompleteness is
  secretly closed internally, and the corpus has not noticed).

**Both outcomes are results.** There is no null.
