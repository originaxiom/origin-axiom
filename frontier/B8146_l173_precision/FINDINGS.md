## Why

B8094 recorded `precision_figures_extracted: False` and said why in its own scope: *"abstracts do
not carry them and full texts were not obtained."* The owner's package asked specifically for
**"what precision on edge-state energies/counts is experimentally standard."** This gets the full

## What the load-bearing anchor actually reports

**Verbin–Zilberberg–Kraus et al., arXiv:1403.7124 (PRB 91, 064201):**

| | |
|---|---|
| array sizes | **13–28 waveguides** — 21 for boundary states, 28 for the phase study, 13 for pumping |
| phason sampling | **thirteen discrete fabricated arrays** for `φ ∈ [0, 2π)` — ≈ `π/6` spacing |
| error bars / uncertainties / resolution limits | **none, anywhere** |
| mode counting | **not done** — boundary modes shown *qualitatively* (*"light … remains there"*), as localization patterns, not numerical counts |

**It is a demonstration paper, not precision metrology.** A targeted search across the AAH cold-atom
edge-state line surfaced no experimental resolution or edge-count figures either.

## The finding

**The column is empty because the field does not report the quantity.** That is not a retrieval
failure — the figures are absent from the source, not from the search.

**And the deeper point.** Our banked prediction is a **count** — `ρ ↦ edge content`, 5-vs-6 at
`ρ = α` — **not an energy**. So the right question was never *"what energy resolution is standard"*
but *"can they count modes in a labelled gap"*. **They do not currently make that measurement.**

> **So the prereg must state a required OBSERVABLE — the number of edge modes in a labelled gap —
> not a required resolution.** The programme supplies the **knob** (the phason is our intercept,
> B8094) but not the **readout**.

**This is more useful than a number would have been.** A resolution figure is a threshold to clear;
a missing measurement is something to commission, and it is exactly what an experimentalist would
need to be told.

## Consequence for the falsification route

B8094 established the route **exists**, because the knob exists and is standard practice. **B8146
narrows it:** the route exists but the readout does not, so *"who can falsify us"* must **commission
a mode count** rather than assume one.
