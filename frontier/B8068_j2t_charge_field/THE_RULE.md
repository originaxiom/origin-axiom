# THE RULE — a negative is a boundary marker, not a terminus

**Owner directive, 2026-08-17, standing.** Carved here because this arc is where it was
earned.

> Report a negative as **"X is unreachable BY CLASS C"**, never as "X is unreachable",
> and always follow it with what lies outside C. The class boundary IS the next axis.

## WHY IT HOLDS EVEN FOR TRUE NEGATIVES

The **rank ceiling** is a real theorem — centralisers preserve rank, proved, and
independent of every import. Treating it as a *wall* was still the error: the entire
physics path came from **outside its class**, from stabilisers of vectors rather than
centralisers. A correct theorem was mistaken for a terminus for months.

## THE QUALIFICATION THAT TRAVELS WITH IT

**"Search until positive" must never mean loosening a gate.** The same session produced
the mirror failure: naming `ℚ(√77)` as the field of the pure spinors off a **single**
split prime, against a density that contradicted the model it assumed. Both directions
are live.

Keep every control — control inside the same script; never infer a type from a dimension;
gate candidates before use, not after; density before identity; no silent skipping — and
keep searching.
