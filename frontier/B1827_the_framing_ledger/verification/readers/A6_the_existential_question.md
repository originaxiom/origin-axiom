## 2. Is the question well-posed? The alternatives, and what the tests measure

### 2.1 Why "derive the 19 from the principle" is not well-posed as the record now stands [V, then I]

   them to physics (identification I-26) is UNEARNED" (GENESIS.md:243-244). FK11 is "UNEARNABLE within F-HE and F-CI on
   any thread or cover of a thread" (GENESIS.md:424). A value "of the object" therefore has no meaning until a frame is
   named. Every value test is a test of (object ∧ frame ∧ chosen inputs). **[V]**
2. **Inside the working frame, the compared values are not invariants.** "Under the generations' full kinetic freedom no
   function of the six, the CKM moduli or J is invariant … FR-FIB fixes the frame in the chosen metric H = I (B1822)"
   (KIND_TABLE.md:49-53). B1822: "the flat structure leaves H free — 8 real parameters per field … a democratic 0.1
   mixing shifts the mass ratios by 0.045 decades and |V| by 0.08 … H = I is a CHOSEN input"
   (frontier/B1822_t_norm_on_the_frames_matter/arc_verdict.json:26). The values the scoreboard counts are gauge-dependent
   quantities of a frame. **[V]**
3. **The observable is not fixed by the question.** The object supplies no scale (GENESIS.md:355-361; WHAT_WOULD_COUNT.md:184-189).
   The comparison scale is therefore "a convention" (PREREGISTRATION.md:224), "a choice (P-489)" (THE_FINAL_ACTS_BAR:226).
   CROSSING_REQUIREMENTS asks that "the boundary-to-measurement interpolation is derived, not assumed"
   (CROSSING_REQUIREMENTS.md:51). In practice the frame's outputs are read as running values at M_Z, at tree level. **[V]**
   I find that the choice moves χ²_ten by about 13 (§3, CE-1). **[C]**
4. **The plenitude form rests on a premise the foundations do not derive** ("NOT DERIVED", THE_FINAL_ACTS_BAR:81-88).
   **[V]**
5. **What "forced" can mean is defined only per frame,** through the FORCED/ADMITTED/CHOSEN/FITTED labels with scope
   (WORKING_RULES.md:433-448). **[V]**

**[I]** The question is therefore well-posed only after it says **which map** from object to fields is under test, how
that map is charged, and **at what scale and with what theory error** its outputs are read. Until then, "n of 19"
measures the frame plus conventions, not the object.

import numpy as np
from scipy.integrate import solve_ivp
v=246.22; MZ=91.1876
m={'u':1.23e-3,'c':0.62,'t':171.7,'d':2.7e-3,'s':0.054,'b':2.86,'e':4.87e-4,'mu':0.1027,'tau':1.746}
lam,A,rb,eb=0.2250,0.826,0.159,0.348
rho=rb/(1-lam**2/2); eta=eb/(1-lam**2/2)
s12=lam; s23=A*lam**2; s13c=A*lam**3*(rho-1j*eta); s13=abs(s13c); d=-np.angle(s13c)
c12,c23,c13=np.sqrt(1-s12**2),np.sqrt(1-s23**2),np.sqrt(1-s13**2); e=np.exp(1j*d)
V=np.array([[c12*c13,s12*c13,s13/e],[-s12*c23-c12*s23*s13*e,c12*c23-s12*s23*s13*e,s23*c13],
            [s12*s23-c12*c23*s13*e,-c12*s23-s12*c23*s13*e,c23*c13]])
k=np.sqrt(2)/v
Yu=V.conj().T@np.diag([m['u'],m['c'],m['t']])*k; Yd=np.diag([m['d'],m['s'],m['b']])*k
Ye=np.diag([m['e'],m['mu'],m['tau']])*k
g=np.array([np.sqrt(5/3)*0.35740,0.65170,1.2177]); b=np.array([41/10,-19/6,-7])
def pack(Yu,Yd,Ye,g):
    Yu,Yd,Ye=[np.ascontiguousarray(X,dtype=complex) for X in (Yu,Yd,Ye)]
    return np.concatenate([Yu.ravel().view(float),Yd.ravel().view(float),Ye.ravel().view(float),g])
def unpack(y):
    c=np.ascontiguousarray(y[:54]).view(complex); return c[:9].reshape(3,3),c[9:18].reshape(3,3),c[18:27].reshape(3,3),y[54:]
def rhs(t,y):
    Yu,Yd,Ye,g=unpack(y); g1,g2,g3=g**2
    Hu=Yu@Yu.conj().T; Hd=Yd@Yd.conj().T; He=Ye@Ye.conj().T; T=np.trace(3*Hu+3*Hd+He).real; f=1/(16*np.pi**2)
    return pack(f*((1.5*(Hu-Hd))@Yu+(T-(17/20*g1+9/4*g2+8*g3))*Yu), f*((1.5*(Hd-Hu))@Yd+(T-(1/4*g1+9/4*g2+8*g3))*Yd),
                f*((1.5*He)@Ye+(T-(9/4*g1+9/4*g2))*Ye), f*b*g**3)
def obs(y):

    def sv(Y):

    su,Uu=sv(Yu); sd,Ud=sv(Yd); se,_=sv(Ye); Vc=Uu.conj().T@Ud
    J=np.imag(Vc[0,1]*Vc[1,2]*np.conj(Vc[0,2])*np.conj(Vc[1,1]))
    return np.log(np.array([su[1]/su[2],su[0]/su[2],sd[1]/sd[2],sd[0]/sd[2],se[1]/se[2],se[0]/se[2],
                            abs(Vc[0,1]),abs(Vc[1,2]),abs(Vc[0,2]),abs(J)]))
sig=np.array([0.1038,0.1979,0.1327,0.1231,0.1000,0.1000,0.1000,0.1018,0.1029,0.1077])
