## The question

The value verdict is closed on the object's PERIODS (V-3/B1126 + the wave: disjoint, exhaustive).
A **regulator** is a different object — the archimedean realization of an arithmetic class (what
Vol = 9√3·ζ_K(2)/π² and entropy = 2√5·L(1,χ₅) already ARE). This probe asks: **is any SM
dimensionless value a bounded-height algebraic combination of the object's HIGHER regulators
(untested), in the two arithmetic ends and — Tier B — the forced J₃(𝕆) domain?**

## THE ADMISSIBILITY REFRAME (load-bearing — why this is not numerology)

Per `docs/LISTENING_PROTOCOL` and INPUT_COMPLETENESS item 10: a single-number match
"regulator ≈ SM value" is **rung 4 — DEAD ON ARRIVAL, however small the σ-distance** (two reals
are always close at some scale). The ONLY admissible test is **rung 1: ALGEBRAICITY** — is the SM
value algebraic (a bounded-degree, bounded-height ℚ-relation) over the object's regulator field?
That is falsifiable to precision. This probe runs rung 1 ONLY; rung-4 matches are excluded a
priori and will not be reported as anything.

## §C — THE TEST (rung 1, PSLQ/lindep, height-aware, exact-verified)

For each SM target V: search for an integer relation of bounded height H and bounded degree D
among {1, V (and V², V³ for algebraicity), the §A regulators, π, √3, √5, log φ, ζ(3)} at working
precision ≥ 60 digits. A candidate is admitted ONLY if:
1. the relation's residual < 10^(−(precision − coefficient-height margin)) — a **coefficient-
   height-aware threshold** (E25: unbounded-coefficient false witnesses are excluded by scaling
   the bound by the coefficient height), AND
2. it survives **exact verification** (symbolic / exact-arithmetic re-derivation, not residual
   alone), AND
3. it survives the base-rate control (§D).

## §D — THE MATCHED NULL + LOOK-ELSEWHERE (item 7, item 8)

- **Matched null:** replace V by N ≥ 500 random surrogates drawn from the SAME measure the
  criterion uses (matched range + transcendental "type": products of the same constants with

  base rate per (degree, height) cell.
- **Look-elsewhere:** the correction covers the FULL grid (targets × degrees × heights × relation
  forms), Šidák/Bonferroni over the whole family, not the headline.

## §E — OUTCOME GRAMMAR (pre-registered; all outcomes bank)
