# B8102 — the cusped one-loop problem is a LITERATURE GAP, and we hold the input that is usually hardest

**Date:** 2026-08-20 · **Seat:** cc3 (audit, WebSearch) · **Verdict: PROVED** (a literature

## The question this answers

B8101 ended with one named gap: **the spin-2 test function for a CUSPED quotient.** Is that
something we failed to look up, or something nobody has?

## Finding 1 — the physics literature EXCLUDES our case, explicitly

**"A spool for every quotient: One-loop partition functions in AdS₃ gravity", arXiv:2507.05364**
(2025) — the current comprehensive treatment — states its scope as:

> *"massive spinning fields on all smooth, **cusp-free**, solutions of Euclidean gravity with a
> negative cosmological constant"*

**Cusp-free.** Our object is finite-volume and **cusped**. So it is not that we searched badly: the
state-of-the-art paper **deliberately excludes** the case, and the exclusion is in its abstract.

## Finding 2 — but the MATHEMATICS for cusped determinants exists

**"Analytic torsion versus Reidemeister torsion on hyperbolic 3-manifolds with cusps",
arXiv:1206.0228**: for a non-compact hyperbolic 3-manifold with cusps it proves *"an explicit
formula that relates the regularized analytic torsion"*, via *"special values of **Ruelle zeta
functions**"*. Companion: **arXiv:math/0111175**, eta invariants and regularized determinants for
odd-dimensional hyperbolic manifolds with cusps.

**Ruelle zeta is built from the geodesic spectrum — the object B8100 computed.**

## THE FINDING — the gap is a BRIDGE, not a void

**The cusped determinant machinery exists in the mathematics literature. The AdS₃ one-loop
application excludes cusps. The two have not been joined for this case.**

That is a materially different statement from *"we need to invent a test function"*. It is the same
shape as **L166**: an **absent** result, not an **unfound** one — but here the absence is a
*connection*, and both endpoints are published.

## AND WE HOLD THE INPUT THAT IS USUALLY THE OBSTACLE

The literature's own remark on this class of problem: **the scattering determinant is generally
hard to compute explicitly.**

**Ours is known in closed form** — B739: `φ_m004(s) = Λ_K(s−1)/Λ_K(s)`, verified in B8101 to satisfy
the `H³` unitarity condition `φ(s)φ(2−s) = 1` to `<1e-25`, with `φ(1) = −1`.

**So the object is an unusually good test case for building the bridge**: the hardest input is
already exact, the geodesic side is computed, and the volume is exact. **That is not a claim that
the bridge is easy — it is a claim about which end of it is already anchored.**

## WHAT I AM NOT CLAIMING

- **Not** that we can build the bridge, or that it is a short computation. It is research-level.
- **Not** that no cusped one-loop result exists anywhere — I read abstracts, not the full papers,
  and a specialist may know of work these searches did not surface. **The honest label is
  NEEDS-SPECIALIST-CONFIRMED**, exactly as L166 ended.
- **Not** a partition function. Nothing here computes one.
