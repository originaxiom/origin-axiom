## Caveats (each one sentence; B = blocking, N = not blocking)

1. (B for the stated reading, N for the run) A pass of the thirteen methods does not test that the compensators are automorphisms of the 248-dimensional E8 algebra: a sign flip on the spinor modules passes C2 to C4 and C6 (plant_sign.py).
2. (N) Methods C8 and C12 end in vertex-normalisation checks in which the length and coupling factors cancel by typing, so they cannot confirm that normalisation.
3. (N) C13 does not compute an index; the word "index_cancellation" in its name must not be read as a result.
4. (N) C5 is mostly typed arithmetic and C9 is mostly typed arithmetic and a standard identity; only a typo in the typed numbers can fail them.
5. (N) C6 tests five words and three moves, not "all words".
6. (B unless the run is in a fresh clone with no untracked or ignored file and no PYTHONPATH) The wrapper's clean check sees tracked files only and the run is not under -I, so a shadow module or a stale .pyc is not detected (D4).
7. (N) Review and acceptance objects are bound only in form: booleans and the string "main" in JSON, and ancestry of the acceptance commit in a local tracking ref; main's own acceptance commit is the control (D2, D3).
8. (N) 43 of 64 pinned hashes and the interpreter and package versions were partly or wholly masked to me; the wrapper re-checks them in full at admission (A2, B6).
9. (N) No timeout or memory bound on a run of exact sympy over 150- to 248-dimensional matrices; an operational failure is not a false pass (D8).
10. (N) The engineering fixtures test a sentinel in place of the real V3 runner and one fixture tests its own helper (E1, E2).
11. (N) I did not read the thirty gate bodies in gates.py, scripts/checks/*.py, scripts/views/generate.py, nor the seven proof inputs; admission also depends on them (D6).
12. (N) C10 and parts of C11 and C13 are symbolic computations with undetermined functions that I did not re-derive; I read them for design only.

## Proposed verdict

APPROVE_EXECUTION with the caveats, on the condition of caveat 6 (fresh clone with nothing untracked or ignored, PYTHONPATH unset, the specified Python and package versions) and on the reading restriction of caveats 1 to 5: a pass is to be recorded as "the thirteen exact finite controls pass", and not as faithful compensator action on E8, all-word covariance, canonical vertex normalisation, or index cancellation. No unresolved finding makes the execution unsafe or the gate fail open; the unresolved findings concern what a pass would mean.
