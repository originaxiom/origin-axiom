  The meridian mu = a (Wirtinger generator).

  tr(A)   = 2
  tr(A^-1)= 2

  theta(mu) = mu (single letter). tr unchanged.
  iota(mu) = mu^-1. tr(A^-1) = tr(A) at SL(2). tr(Sym^2(A^-1)) = tr(Sym^2(A)).
  RESULT: tr(T) is theta-INSENSITIVE and iota-INSENSITIVE.

3b. iota commutes with ALL homomorphisms

  For any homomorphism phi: F2 -> F2,
    phi(g^-1) = phi(g)^-1  (homomorphism property)
  Therefore iota . phi = phi . iota on all of F2.
  In particular: iota . sigma = sigma . iota.

  Verify: sigma(a^-1) = (AB)^-1 = [[1, -1], [-1/2 + sqrt(3)*I/2, 3/2 - sqrt(3)*I/2]]
  Verify: iota(sigma(a)) = (AB)^-1 = [[1, -1], [-1/2 + sqrt(3)*I/2, 3/2 - sqrt(3)*I/2]]
  Equal? True

  Consequence: iota commutes with the trace map T_sigma
  at ALL ranks (it commutes with sigma itself).
  No trace-map dynamics can detect iota.

3c. Trace map T_sigma = T_sigma_mirror at SL(2)

  sigma: a->ab, b->a
  sigma_mirror: a->ba, b->a

  T_sigma(x,y,z) = (z, x, xz-y)

  T_sigma_mirror:
    tr(sigma_m(a)) = tr(ba) = tr(ab) = z
    tr(sigma_m(b)) = tr(a)  = x
    tr(sigma_m(a)*sigma_m(b)) = tr(ba*a) = tr(a^2*b)
      = tr(a*b*a) [cyclicity] = tr(a)*tr(ab) - tr(b) = xz - y
  T_sigma_mirror(x,y,z) = (z, x, xz-y) = T_sigma.  IDENTICAL.

  RESULT: The trace map is theta-INSENSITIVE at SL(2).
  (And at all higher ranks, since theta = id on all traces.)
