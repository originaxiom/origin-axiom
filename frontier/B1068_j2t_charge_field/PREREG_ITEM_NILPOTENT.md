# PREREGISTRATION — item 1: nilpotent orbits and Bergmann operators

**Sealed 2026-08-17, committed BEFORE the panel runs.** Rule 1.

## THE HYPOTHESIS UNDER TEST

Our rank ceiling's proof reads: *the centraliser of a set of **semisimple** elements contains
a maximal torus, therefore has full rank.* **The word "semisimple" is load-bearing and has
never been tested.**

Verified in `sl(2)`: the centraliser of the nilpotent `e` is 1-dimensional, contains no
Cartan — **rank drops 1 → 0**. So nilpotent centralisers *can* reduce rank, and the ceiling
never covered them.

Two independent lines point at the same door. Nilpotent orbits directly; and Bergmann
operators `B(x,y) = 1 − D(x,y) + Q_xQ_y`, which lie in the structure group of the Jordan pair
— hence in `E₆` — so their fixed algebras are centralisers of **group elements**, covered by
our no-go *unless the element is unipotent*.

## THE CONSTRAINT THAT MAKES IT INTERESTING

A **compact** real form has no nonzero nilpotents: its Killing form is definite, so every
element is semisimple. **Nilpotent orbits exist only in non-compact forms.** And `B907` found
this object's first measurement wall real in **`e₆(2)` and only there** — non-compact,
quaternionic, real rank 4.

Two facts, found independently, pointing at one place.

## WHAT WOULD MAKE THIS A FALSE POSITIVE

Claiming a rank drop from a centraliser computed at a **non-semisimple** element without
checking that the element is genuinely in the algebra the object supplies. The object must
*determine* the nilpotent, not merely admit one — rule 8. `e₆` has nilpotent orbits in
abundance; that is not the question. The question is whether **this object's** data lands on
one.
