# Designs v1 and v2, kept as disclosed history

- `B1653_PREREGISTRATION_v1.md` and `twisted_zero_mode_v1.py`: design v1 ("the twisted zero mode"), whose headline (a
  lift of the first generation by a flat line) was false for the record's coupling: it dropped the identity unit's
  residue R₁. The first review pass found this, and main re-derived it.
- `the_rank_of_a_point_coupling_v2.py`: design v2's instrument. Its U6 (a radially symmetric spread profile about a
  regular point) could not lift, by the mean-value property; the apparent lift was aliasing. The second pass found
  this. Design v2's preregistration text was revised in place into v3 (the sealed PREREGISTRATION.md); the findings
  against it are listed in the preregistration's §0b, item 4.
