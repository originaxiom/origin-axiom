## 2. The defect: the stated metallic mechanism proves the wrong half

The bundle argues the metallic family can never have an arrow via:

> *"for any symmetric A ∈ SL(2), `S A S⁻¹ = adj(A) = A⁻¹` … So symmetry is forced; **no choice of
> m yields an arrow**."*

**The symmetric identity is true — verified symbolically for a general symmetric A — and it
establishes the wrong thing.** `det S = +1`. So symmetry supplies the **det = +1** conjugator,
which is **amphichirality**. *No arrow* requires the **det = −1** conjugator, and symmetry does
not supply it.

> **The counterexample is already inside the bundle's own table.**
> **LLRLRR = [[2, 5], [5, 13]] is symmetric — and it has an arrow.**

A symmetric trace-15 matrix with an arrow refutes "symmetric ⟹ no arrow" outright. The argument
proves amphichirality (true, and already in the table) and is silent on the arrow.

**The conclusion nevertheless survives, and here is the mechanism that actually carries it.**
Computed over m = 1…12: every `M_m²` has **no arrow**, and in every case
**disc = m² + 4**. That is the whole reason —

> the metallic mean `(m + √(m²+4))/2` has norm `(m² − (m²+4))/4 = **−1**`,
> so the order contains a unit of norm −1, so the det form represents −1, so the det = −1
> conjugator exists, so there is no arrow. **One line, for every m at once.**

This also explains the bundle's own error #4 (*"wrong Pell equation — D = 8 has even period yet
represents both"*): the relevant order is the one generated by the **metallic mean**, of
discriminant m²+4 — not `ℤ[√D]`. At m = 2 the metallic order `ℤ[1+√2]` has fundamental unit
`1+√2` of norm −1, while `ℤ[2√2]` has fundamental unit `3+2√2` of norm +1. **Right field, wrong
order** — the same "right object, wrong level" shape already in `PRACTICES`.

**Correct conclusion, wrong stated reason** is the defect class this programme cares most about:
it is a hypothesis nobody listed, which is what the bundle's own §6 names as the generalisable
lesson. It arrived attached to the very result that lesson was drawn from.
