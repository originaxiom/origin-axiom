## The false positives have ONE shape, and it is fixable

**All five carry their scope INSIDE the claim as a domain restriction** —
*"trace-ring"*, *"through index 6"*, *"zero-measure"* — which `CLAIM_CARRIES`
does not recognise as fencing. **The instrument reads only hedge-words, not
scope-words.**

**Fix, mechanical:** treat a claim as fenced when it contains a **domain
restriction that matches the body's fence subject**. Cheap, and it should lift
precision materially.

**Not applied here.** cc3 is not tuning an instrument against the sample it just
measured — **that is post-hoc selection and the corpus has an error class for it
(E29).** The refinement is proposed for cc, to be validated on a **held-out**
slice.
