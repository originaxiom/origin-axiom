1. **`A2 = c = 6σ`** — in **B1015 only**. B1015 says it maps R11's allowance onto

   continuous dimensionless coupling.** Either B1015 is mapping *anchors* rather

   input.** **L154 decides whether it discharges — and it is now preregistered.**

   **Choosing which SU(3) is colour is a discrete choice that appears in no other
   enumeration.** Not a synonym: chirality is τ ≠ id; the split is a colour
   labelling. **Unassessed by the discharge audit.**
3. **P, the record swap** — in **B16 only**, which states it is not forced by
   A1–A6. **Inert** for the derivation theorem (`ab = 1` over positive integers
   already forces `a = b = 1`, so the half-step's selection is redundant), **but
   uncounted everywhere.**
