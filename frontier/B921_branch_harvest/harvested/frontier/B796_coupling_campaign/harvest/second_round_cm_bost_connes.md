## 1. Mechanism summary — why BC systems are the adjacent dynamics-native framework

The Bost–Connes (BC) paradigm is precisely the inverse of the programme's banked picture, which is what makes it attach on the observer side:

- A BC-type system is a C*-dynamical system (A, σ_t) where the **time evolution is generated by the arithmetic norm** (H = log N on ideals). Dynamics is *built in*, not emergent — the "arrow" the tracial II₁ substrate lacks.
- **Partition function = ζ_K(β)**; the KMS_β equilibrium structure has a phase transition at exactly **β = 1, the pole of ζ_K** — matching the campaign's banked "critical β of the SSB measurement transition is the pole of ζ_K, K = Q(√−3)" verbatim on the BC side.
- Phase diagram (K any number field, LLN theorem): for 0 < β ≤ 1 a **unique** KMS_β state (a type III factor state — the "thermal observer" side); for β > 1 the symmetry **spontaneously breaks** and extremal KMS_β states form a principal homogeneous space under **Gal(K^ab/K)** ≅ idele class group quotient (Gibbs states, type I). At β = ∞, values of the extremal states on a canonical arithmetic subalgebra generate K^ab, with the symmetry action intertwined with the Galois action.
- **Cooling is a functor, not a metaphor** in this literature: Connes–Consani–Marcolli's "thermodynamics of endomotives" defines a *cooling morphism* and *distillation* procedure that passes from the type III BC equilibrium data to a type II dual system whose scaling action carries the zeta zeros. Type III observer → cooling → type II object is literally the banked m004 arrow, run in the same direction.

So the one-line mechanism match: **BC side supplies (flow, β=1 transition at the ζ_K pole, Galois symmetry of the broken phase, III→II cooling); the m004 bank supplies (II₁ trace, thermal type III observer, β=1 SSB, K = Q(√−3)).** The interface is the observer side, exactly where the bank says dynamics must attach.

## 6. Failure modes — why BC might NOT attach

1. **No Bianchi BC system exists** (Section 4). The honest GL(2)-over-Q(√−3) object in the literature is the CM/Shimura side (elliptic curves, H²), not the Bianchi side (H³) where m004 lives. Attaching CMR to m004 uses only the trace field and cusp CM data — the hyperbolic structure itself is invisible to every existing BC construction.
2. **Interface type mismatch is real**: a II₁ trace is a KMS state only for trivial modular flow (β-independent); no BC system has a tracial KMS_β at finite β. The attachment can only be: II₁ object = *cooled/distilled dual* of a type III BC observer (paper #10's mechanism), never a direct KMS phase. If the bank's cooling arrow cannot be functorially matched to the CCM cooling morphism, the analogy is verbal.
3. **The time evolution is imported, not intrinsic**: BC dynamics comes from N(a), i.e. from Spec O_K. The programme's banked claim is that dynamics must attach on the observer side — BC is consistent with that, but it means BC dynamics can never be *derived from* m004's internal II₁ algebra; it is an external choice, and T6 may show it is not even m004-specific.
4. **Maass-form obstruction**: the β=∞/Galois half of the mechanism needs an arithmetic subalgebra of "algebraic modular functions". On the Bianchi side these would have to come from Maass forms, which are not known (and mostly not believed) to carry the required algebraicity. If B796 needs KMS_∞ values to be periods of m004's own spectrum, that mathematics does not exist.
5. **Six units**: μ₆ for Q(√−3) is maximal among imaginary quadratic fields and is exactly what broke the 1997/1999 constructions (wrong symmetry group). Any hand-rolled in-cell presentation must handle the μ₆ quotient correctly or it will reproduce the historical failure — worth an explicit regression test against the LLN classification.

Bottom line: the framework fits the banked mechanism (β=1 SSB at the ζ_K pole, Galois symmetry of the cold phase, III→II cooling) remarkably tightly on the GL(1)/CMR side, all key facts verified; the GL(2)-over-K/Bianchi slot the campaign actually occupies geometrically is **verified empty** in the literature — which is both the risk (nothing to cite) and the opportunity (T1–T6 probe whether m004 forces the object that should fill it).
