# Evidence returned for each AGY checkpoint

Template only. Empty fields confer no approval. The author supplies the
first section; the physical seat supplies its assessment separately.
Required nonauthoring review, main acceptance and admission remain distinct.

## Author return

- Local task ID and exact question:
- Author branch, full commit and immutable source/design/spec hashes:
- Object manifest and changes from the previous accepted object:
- Claim, quantifier, hypotheses and claimed evidence type:
- Reused results and exact source locations; why their domains apply:
- Derivation and witness locations:
- Full before/after independent-input table:
- Physical identification supplied, derived, or still missing:
- Countercontrols and the mistake each must reject:
- Required source-complete reviewer, main acceptance and admission pins:
- Actual command/environment and raw first output, if admitted and run:
- Failed attempts, limitations and unresolved alternatives:
- What downstream statements would become justified if accepted:

Never report a planned command as run, a numerical decimal as an exact
certificate, or an author's self-check as external review.

## Separate physical-seat assessment

- Reviewer identity and nonauthoring scope; any authorship conflict:
- Exact reviewed claim, commit and source/dependency closure:
- Object, representation, marking, norm and domain joins checked:
- Proof steps independently checked and remaining assumptions:
- Code/proof agreement and witness validity:
- Countercontrols inspected/reproduced; precise admission for any run:
- Numerical/exact/analytic scope, errors and completeness limitations:
- Positive results preserved:
- Negative results and their exact reach:
- Input-reduction category: model simplification / conditional constraint /
  foundational removal / none / unresolved:
- Decision: REVISE / ACCEPT_SCOPED_RESULT / UNRESOLVED:
- New dependent work justified and prohibited claim promotions:

This assessment does not automatically provide main's separate exact
execution acceptance, merge a result or bank a scientific theorem. If
the physical seat materially authors the new proof/producer, it cannot
serve as that packet's nonauthoring reviewer; another reviewer is needed.

## Questions the reviewer must actively try to falsify

1. Is this the same physical object and operator throughout?
2. Did the complete roster or an essential boundary/continuum mode vanish?
3. Was a field, mass, current or family map inserted by name or tensoring?
4. Does the supposed reduction return through spin, holonomy, norm or state?
5. Can the named wrong witness pass because only its count is checked?
6. Is a true finite/special-case result being promoted to a universal one?
7. Is a failure of one model being promoted to a universal no-go?
8. Were outputs generated under the actual reviewed specification?
