  worker; switch only at saved/reviewed checkpoints.
- Start from a short explicit run ticket: task/subtask ID, exact object

  report waiting for review rather than execute the whole roadmap.

  Do not paste entire repository logs, all parent papers or all future
  tasks into each context. Retrieve additional dependencies when needed.
- A handoff locates evidence; it does NOT turn its summary into proof.
  Recheck source bytes and read the load-bearing argument for each new
  claim. Preserve qualifiers, counterexamples and unresolved issues.
- If the subtask still becomes too large, save a partial handoff and
  propose a smaller named subdivision. Do not compress an unresolved
  proof into 'verified' to make it fit. Use a fresh host context/session
  when needed; no particular model capacity or reset API is assumed.
- Save state before a context transition and at each substantive result.
  Never depend on the worker remembering the previous conversation.
- Resume only the released subtask. Completed author work is unreviewed
  until separately accepted; author completion cannot release dependencies.
