## How to read the checklist

`[x]` means the explicitly scoped task has a local result and evidence.
It does NOT mean the originating object uniquely forces its assumptions,
that all other seats agree, or that nature has verified it. `[ ]` means
the stated completion test is not discharged in this audited construction.
It is not a universal claim that no relevant work exists in the corpus.
The supplied archive has been read directly, but neither fetching all
branches nor scanning every reachable blob is reading and proving every
result on every branch.

## 2. Critical path and completion tests

The main dependency is:

    common model and inputs
        -> coupled source/end solution and actual domain
        -> full spectrum + anomaly + normalized interactions together
        -> controlled 4D SM limit and quantitative tests
        -> same-theory gravity, quantum completion and cosmology

Physical consistency checks run at every step, not only at the end.
Gravity must not be appended as an unrelated action after the matter
theory is declared complete. Its dictionary/embedding requirements are
recorded early even while the sourced-matter calculation has priority.

### A. One common model and an honest input budget — PARTIAL

- [ ] Fix one geometry, physical spacetime interpretation, global gauge
  group, bundles, fields and action in which the desired results coexist.
- [ ] Distinguish derived data, ordinary physical inputs, gauge/coordinate
  conventions, and hypotheses awaiting verification. Quotient redundant
  choices before counting observable free parameters.
- [ ] Exhibit actual maps between the algebraic, geometric, fermionic and
  gravitational descriptions. Matching names, dimensions or abstract
  groups is not an identification.

Done when: one model specification permits an unambiguous computation
of observables without changing the parent group, domain, real form,
matter content or approximation between successful subsections.
R4's parent fundamental 27 cannot simply be imported into R20's
E6/Z3 parent; R21's explicit subgroup map is a narrower, valid tool.

## 3. Alternatives kept live, with a rule for changing course

- Partial filling: derive an actual boundary theory and quantum level,
  including its field map and anomalies. Nonzero geometric CS is not enough.
- Curved-cone/enhancement route: verify its local geometry, global gauge
  form, fermion operator and matter index before transferring a literature
  spectrum. It is outside the tested unresolved-flat-cone exclusion.
- Nonabelian or differently sourced transport: a live alternative when
  it genuinely changes a hypothesis of an existing no-go. Recompute the
  resulting action and operator; do not reuse the flat cohomology silently.
- Paper transfers: target the recorded spinorial, relative-index,
  CS-flow, character/skein and end-operator tools only where their
  geometric/domain/positivity hypotheses match.

The primary source path stays first because it has an actual conditional
chiral kernel and a stationary bulk background. Change course if a
load-bearing proof fails, if a specified completion is inconsistent, or
if an alternative provides a demonstrably better common-model bridge.
For a failed candidate, record exactly which hypothesis failed and test
the named escape; do not rerun the same mechanism under a new label.
Do not make the mission unfalsifiable by freely adding fields until any
desired answer can be fitted.
