1. Run the eight upstream test files B1242, B1247, B1248–B1253 unchanged;
   preserve the complete subprocess stdout/stderr, return code and duration.
   Test success establishes what the tests execute, not all accompanying prose.
2. Independently compare B1252's solved metric with the exact Bourbaki Cartan
   inverse already used in B970/R4. Recover every root from *all* nonzero
   matrix entries, not a single entry. Naive Euclidean metric is the negative
   control. Root length 2 is a normalization constraint in B1252, whereas
   weight length 4/3 is an independent consequence.
3. For the D2 stabilizer, recover a simple-root Cartan matrix and its rank and
   graph, in addition to root counts. Derive the actual weight-block actions.
4. Use the published B1252 witness [0,-5,-4,5,-2,2] in its weight-coordinate
   convention; convert with the metric to a Cartan charge functional. Normalize
   its multiplicity-six charge to 1/6, explicitly an imported convention.
   Compute the SU3 and SU2 root actions on the 16; check the six connected
   multiplets and charge conservation, not just the hypercharge histogram.
   Trace Y, Y^3, H_color^2 Y, H_weak^2 Y and H_color^3 on the actual 16.
   Count SU2 doublets from its root action. A shifted charge must fail.
5. Enumerate every coefficient triple in [-6,6]^3 in a deterministic
   nullspace basis for the *fixed* SU3+SU2 centralizer. Deduplicate normalized
   charge functionals and retain all SM-histogram hits. This is a finite-box
   check, not an exhaustive classification of real directions. Two different
   hits refute unique direction in that box; zero/one cannot prove unrestricted
   uniqueness. B1252's original first-return loop does not test its uniqueness
   wording. A witness need not be unique to be a valid representation.
6. Exhibit a Weyl element, as a real orthogonal 27 matrix built from the
   simple root matrices, taking R4's S line to B1250's weight 13. Check the
   conjugated 1+10/16 grading equals D2 exactly and that the cubic is preserved.
   This connects the new grading to the existing conditional model without
   silently making a discrete grading into a dynamical symmetry-breaking law.
