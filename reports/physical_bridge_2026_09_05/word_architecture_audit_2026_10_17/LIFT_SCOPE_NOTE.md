# Inverse moves and the boundary word

October 18, 2026. Authored analytical source comparison. No new scientific
producer run, independent proof acceptance or banked claim is asserted.
This note specifies a control for the whole-word investigation.

## The distinction to preserve

Main's B1662 adopts inverse matrix moves and reaches the homology sign
-I. That does not by itself introduce every word automorphism whose
homology is -I. B1634's word-level source already enumerates both forward
and inverse moves. Consequently the inverse-move ruling alone is not a
reason to restore the extra inner symmetries used in earlier flavour
negatives. Those require their actual based lift, not its matrix label.

This preserves a possible route; it neither derives the physical lift
choice nor certifies the older spectrum calculations.

## Exact conventions from the source

Work in the free group F2 on a,b. Write A=a^-1 and B=b^-1. Composition
f g means f after g, so f g(x)=f(g(x)). Use the generators in
B1634's `verification/w50_on_main.py`:

    L(a)=a,  L(b)=ab,       L^-1(a)=a,  L^-1(b)=Ab,
    R(a)=ab, R(b)=b,        R^-1(a)=aB, R^-1(b)=b.

On abelianization these give the core matrices
L=[[1,1],[0,1]] and R=[[1,0],[1,1]]. The retained word is

    c = a B A b.

It is this specific based word, not the same spelling as R79's abAB.
Transport between boundary-word conventions must be explicit.

## A finite proof before any new census

Free reduction gives

    L(c) = a (ab)^-1 a^-1 (ab) = a B A b = c,
    R(c) = (ab) b^-1 (ab)^-1 b = a B A b = c.

Since both maps are invertible, their inverses fix c too. Induction on
word length therefore shows that every composition in these four maps
fixes c exactly. In particular, a larger depth search cannot produce
conjugation by a or b: those maps send c respectively to aaBAbA and baBA,
both different from c as freely reduced words.

Now define S=L R^-1 L. Direct substitution gives

    S(a)=aBA,       S(b)=a,
    S^2(a)=aBAbA,  S^2(b)=aBA.

Its homology matrix is [[0,1],[-1,0]], so S^2 has homology -I.
Compare the independent letter-inversion map J:

    J(a)=A,  J(b)=B,  J(c)=AbaB.

The image J(c) differs from c. Thus J is not generated by these four maps,
although it has the same homology -I as S^2. More precisely,

    S^2 = Inn(aB) composed with J,
    Inn(h)(x) = h x h^-1.

Checking this equality on a and b gives the two S^2 images above.
The difference is an inner automorphism: the maps agree as outer
automorphisms and on homology, but not as based automorphisms.

This proof does not need a claim that the entire kernel is generated by
one boundary twist. B1634's stronger B3/kernel statement is existing
work, not reproved or recertified here.

## What this says about the allowed architecture

There are distinct operations which must not be silently merged:

| Operation | What is established for these generators | Additional duty |
|---|---|---|
| Allow L^-1 and R^-1 | Every word still fixes c; S^2 reaches -I on homology | Current inverse legality is adopted in GENESIS v1.48, not derived from PF1 |
| Add the independent map J | Same homology sign, different based boundary action | Admit this map separately or prove its difference is immaterial for the declared theory |
| Forget inner automorphisms | S^2 and J become the same outer class | Show updates, observables, joining and boundary data descend through this quotient |
| Retain based boundary data | The distinction can be tested | Show which retained data are physical rather than coordinate conventions |

The last two rows are complementary. R79 already exhibits correctly
transported peripheral data preserving a description. A based difference
is not automatically a physical difference. AR1–AR2 supplies the relevant
conditional descent test, including future observations; partial maps
also need equal admissibility domains.

The canonical text and B1634 contain historical references to a sign
branch under GM5b. B1662's ruling is explicitly about inverse moves on
the records. Before transferring any old sign-branch exclusion into
the current theory, identify which lift was used. This note does not
declare all those historical results wrong or exhaustively audited.
