## What can be calculated without selecting one root

Start with the admitted updates acting on their common records. Keep
their actual word lifts when an output uses the boundary or basepoint.
Compose finite histories in that shared frame. Take a quotient only
after proving that outputs, legal continuations and subsequent updates
descend. The partial-future quotient in [the typed specification](TYPED_ARCHITECTURE.md)
does this for specified duties; it does not choose those duties.

For infinite histories, distinguish a limiting description from a state
evolving in chronological order. [The infinite-history analysis](INFINITE_HISTORIES_AND_WEIGHTS.md)
proves a nested-cone description of all irrational directions for positive
directives using both moves infinitely often. Its chronological control
does not converge. Signed histories have additional controls with no
universal limiting direction. These statements have different domains;
none makes every admissible history a physical event.

For assemblies, specify the vertex objects, interfaces and matching
maps. [The graph law](GRAPH_JOINING_AND_HIGHER_COHOMOLOGY.md) retains
transports on edges and conjugacy classes of loop transport. Tree frame
choices cannot erase genuine cycle data. The universal representation
law determines compatibility for a supplied graph; it does not choose
the graph or its physical action. Composition of histories and joining
separate carriers remain different operations.

Only then test a physical candidate using its own fields, action,
background, boundary/source terms, operator domain and observables.
Neither a shared group name nor an equal index licenses importing a
spectrum or interaction from a different construction.

### Complementary direction coordinates

The infinite-history proof defines beta(x,y)=y/(x+y), whereas
`extended_checks.py` uses gamma(x,y)=x/(x+y) in `cone` and its
chronological controls. The source does not name this conversion. It is
the same projective direction in complementary coordinates, not two
inconsistent predictions:

    gamma = 1-beta,
    I_gamma = [1-upper(I_beta), 1-lower(I_beta)],
    gamma²+gamma-1 = beta²-3beta+1.

This explains the test's golden polynomial gamma²+gamma-1 rather than
the proof's beta²-3beta+1, while preserving interval length and nesting.
For chronological updates, its lower bound for gamma after L^k is the
proof's upper bound for beta; its upper bound after R^k is the proof's
lower bound. Thus the displayed tests are analytically equivalent under
this map. They still need actual execution and review. The convention
was not explicitly declared in the frozen design, so the reviewer must
resolve that omission; this note does not retroactively amend the seal.
