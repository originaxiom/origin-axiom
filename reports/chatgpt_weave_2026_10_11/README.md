Run `python3 verify_archive.py` here. This checks the complete manifest, ZIP hashes and every extracted member without running scientific programs. Original verification commands remain in the per-run reports and READMEs.

`SOURCE_INVENTORY.json` records source hashes and standalone-to-ZIP matches. `MANIFEST.json` and `SHA256SUMS.txt` cover this checkpoint. `RESTORE_RECEIPT.json`, when present, records publication-side restoration.

No failed or corrected version has been removed. Later corrections are not silently folded into earlier reports. This checkpoint preserves the work; it makes no new claim that the physical programme is complete.
