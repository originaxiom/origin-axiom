## 3. What the tests lock — the belt is thinner than its size

Test digests (`tests.tsv`, lock types as of this draft: RECOMPUTES 468, COMPARES_TO_STORED 187, TAUTOLOGICAL 8,
NOT_A_TEST 3 of 666). Two families deserve the owner's attention:

- **The "REPRODUCES" string family [verified].** 29 test files (B1147–B1185 belt) contain a
  `test_reproduce_*` that asserts the literal string `REPRODUCES` occurs *inside the committed
  reproduce script or its committed output text*, not that running the script reproduces anything
  (`tests/test_b1160_hypercharge_forced.py` l.51–53 is typical: `assert "REPRODUCES" in runners[0].read_text()`).
  These locks cannot fail unless someone edits the text. The seat's own R-cells re-ran several of the
  underlying scripts (R22 harvest chain, R23 carriers, R24 w0 chain, R25 torsor) and found them
  mostly sound, so the *results* stand, but the *belt* on them is decorative. (The `.gitignore` finding
  from R22 is the same defect from the other side: `reproduce_new.sh` writes `.log`/`.out` files that
  cannot be committed, so "8/8 REPRODUCE" is unwitnessed on every head.)
- **OA_SLOW gating.** A large share of the B1100+ tests run the real recomputation only under
  `OA_SLOW=1` and otherwise compare stored JSON fields to themselves; CI as configured never runs the
  recomputation. The readers list these under `SKIP_IN_CI` (see `tests.tsv` red_flags column).
