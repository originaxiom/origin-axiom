## C-i — SURJECTIVITY IS NOT IDENTITY: the verdict must name the map and test it for naturality

*(unchanged from v1 — correct at any k)*

**The defect this closes.** The cell asks whether the torsor generators' 27-shadows *generate*
B936's H¹ = (ℤ/2)². A bare "generates / does not" is a **surjectivity test**, and surjectivity onto
a group of order 4 is a weak property (C-ii prices it). Both sides are (ℤ/2)² with **different
indexings** — the observer torsor vs E₆'s τ-fixed Dynkin nodes (the trivalent node and the branch tip) — and **no identifying arc**,
which is the entire reason L153 exists. An accidental surjection would satisfy a bare verdict form
while identifying nothing.

**The rule invoked is the programme's own, verbatim from main (B916):**
*pin H by equivariance pattern, never basis-primitivity.*

**Required of the verdict, on every branch:**

1. **The explicit map, elementwise.** Record the image of *each mapped* generator-shadow as a named
   element of H¹ in the τ-fixed-node indexing — **the TRIVALENT node and the BRANCH TIP**
   (Bourbaki α₄ and α₂). **These are distinguishable by valence, so no diagram automorphism
   exchanges them and the assignment is a testable claim rather than a convention.** A verdict
   reporting only the image's *size* is INCOMPLETE and is banked as such, not as SAME.
2. **The naturality test.** State whether the correspondence is **equivariant** — stable under the
   automorphisms already banked as acting on both sides (the τ-action on the Dynkin nodes; the
   torsor's own action per B782) — or holds only in the chosen basis. **The target is canonically
   labelled** (C-i.1: the two classes sit at nodes of different valence), which is what makes this
   test discriminating rather than decorative: there is a fact of the matter about which shadow
   lands on which class.
   - **equivariant + surjective → SAME** may be claimed.
   - **surjective, basis-dependent only → PARTIAL-UNPINNED**: the deficit is *not* settled; the row
     banks with the map on the page and the identification withheld. A result, not a failure — it
     names exactly what a later cell must supply.
3. **The negative form is symmetric.** A non-surjective image is recorded elementwise too — which
   subgroup, generated by which shadow — since the *shape* of the failure feeds C-iii.

**No-smoothing clause.** If the map is recorded and the naturality test is not run, the verdict is
**PARTIAL-UNPINNED**, never SAME. Absence of a naturality check is not evidence of naturality.

## C-ii — THE NULL GOES IN THE SEAL (corrected: k is stated by the computation)

**The defect this closes.** B1006's lesson — *a null below power excludes nothing* — applied to a
**positive** for the first time: the convenient outcome (SAME, which sustains the pin and leaves
the input list unchanged) is also an outcome that occurs readily by chance.

**Declared before compute** (cc3's corrected table, branch `0af484fd`; re-derived independently on this bench):

| generator-shadows mapped | generate (ℤ/2)²? | evidence in a bare SAME verdict |
|---|---|---|
| k = 1 | 0/4 = **0 %** | impossible |
| **k = 2 — GOVERNING, per the sealed cell** | 6/16 = **37.5 %** | **1.415 bits** |
| k = 3 | 42/64 = **65.6 %** | 0.608 bits |

**k IS A PROPERTY OF THE COMPUTATION, NOT OF THIS AMENDMENT.** The verdict **states k** — how many
generator-shadows were actually mapped — and cites the matching row. The sealed cell fixes k = 2;
if the compute maps a different number (e.g. the A7-committed shadow turns out to participate), the
verdict says so and uses that row.

**The consequence, stated not smoothed.** At k = 2 a bare "generates" verdict carries **1.42 bits**
and lands on the convenient answer better than **one time in three** by chance. That is **not
admissible on its own as an identification** — not a caveat on a SAME verdict but a disqualification
of the bare form. What lifts SAME above the null is C-i's equivariant elementwise map; nothing else
in this cell does.

**Required of the verdict:** the banked row carries its base rate **on its face**, so downstream
citations inherit the price. Two failure modes are guarded, not one: a bare SAME **overstates**, and
an inflated null **under-states** — a wrong rate would make a genuine identification read as noise
three relays later. The rate must be the *right* rate, which is why k is read off the computation.

## CORRECTION RECORD (banked with the amendment, not footnoted away)

shadows.** The chain, in order:

**Second correction, same round: the node labels.** v2's first draft of C-i wrote the τ-fixed
classes as Dynkin nodes "{1,3}" — an ad-hoc 0-indexed scheme inherited without checking. **Verified

**Third and fourth corrections, same round — both inside C-iii's type clause.** (a) The clause first
inherited "27-visible ⟹ operand-type" and used it one-sidedly; cc3 narrowed its own overstatement,

**The through-line across all four corrections.** Twice this seat's own design amplified an inherited

another apology. cc3's standing correction is the matching rule from the sending side, and belongs

convention it lives in, or express it convention-free.*

**The lesson worth carrying, in the programme's own vocabulary:** *verify-don't-trust* binds to the
**premise**, not only the arithmetic. A correction from another seat is an input to be checked, not
an authority to be adopted — deference is not verification, and re-deriving the numbers *inside* an
unchecked premise is the most convincing way to be wrong.
