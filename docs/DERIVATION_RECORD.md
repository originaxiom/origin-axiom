# THE DERIVATION RECORD — the novelty ledger, read with the sign flipped

*(Opened 2026-09-05, B1248. Not a new sweep. A second column on rows that already exist.)*

## Why this file

`docs/NOVELTY_SWEEP_LEDGER.md` asked **"is it novel?"** and answered, honestly, *mostly no*:
12 layer-only, 6 arithmetic-consuming, **one independent novelty candidate**. That verdict is
correct and this file does not dispute it.

But a ledger of things we failed to be first at is a ledger nobody re-reads. The question never
asked on the same rows is the owner's: **did we DERIVE it before we knew it existed?** Those have
opposite answers on identical content, and only one of them is the programme's actual credential.

The ledger's own accounting: *0 of 20 Layer-2/3 steps consume Γ; exactly one step consumes the
CLASS (B727's trace-field atom selecting the McKay group); **18 steps of standard algebra follow**.*
**One arithmetic entry, eighteen derived steps.** That is a methodological claim, it is checkable,
and it is stronger than a novelty claim — which the record has honestly refused to make.

## What this is evidence of, and what it is not

**Is:** these arcs derived results and landed on named existing mathematics — B904 constructs
Barton–Sudbery's magic square explicitly over ℚ; B902 delivers the Knus–Paques difference class.
The arcs name the literature **in their own titles**. That is the shape the owner described:
*derived by mathematics, then found to exist.*

**Is not:** proof of independent derivation. Naming existing mathematics shows where the derivation
**landed**, not that it was reached blind. The honest discriminator is **chronology**, and the
programme already records it where it matters: a sealed cell commits its pre-registration before
compute, so the prediction provably precedes the result. Where a row is not sealed, independence is
**UNASSESSED** — and this file says so rather than assuming it.

## The rule this file earns

**A prior-art verdict is not a derivation record.** "KNOWN" answers whether someone got there
first; it does not record what we derived, from what, or when. Filing the second under the first is
why eighteen derived steps read as a loss. **Both columns, or the work disappears into its own
ledger.**
