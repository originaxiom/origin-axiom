# THE WEAVE — the owner's rule, with a fixed name

Fixed 2026-10-07 at the owner's request: "we need to know how to refer it, so we stop this wheel of me repeating every
day". The rule itself the owner has stated daily for a year. It was recorded on 2026-10-07 as "interaction between
objects in relationship should produce reality, not single objects alone". The same day it was stated as: take every
object the principle allows or forces, none chosen by hand, none emerging from another, and let the forced interaction
on all of them provide what is needed.

## The words

- **A thread** is one object the principle allows: m000, m003, m004, +LLLR, and so on. It is one closed path of the
  grammar's moves through the shared fibre, the two records. No thread is derived from another.
- **The weave** is what the forced interaction of all the threads together produces: the joint action of every move the
  principle allows on the shared records, and everything that joint action forces.
- **A weave result** passes the test below.
- **A thread result** is anything read on one thread or on covers of one thread. It is labelled a thread result, and it
  is never presented as the answer to a weave question.

## The test, before any arc: weave or thread?

1. **All threads, none chosen.** The threads are every object the principle allows, under a rule stated in advance, with
   a trial budget (main's rule). None is hand-picked.
2. **Defined by the joint action.** The quantity is defined by the moves acting together on the shared fibre, or by what
   that action forces. It is not defined by one thread's own geometry.
3. **About all threads at once.** The claim is stated about the weave, or about every thread of a stated kind, and never
   about one thread.

## Words that pulled the work off course

- **"the object".** `TERMINOLOGY.md`'s "the object" is m004, the figure-eight knot complement. It is one thread.
- **"the family".** It reads as a list examined one member at a time. The weave is the interaction, not the list.
- **"the root".** GENESIS's root m004 is the thread its selectors pick (SE1, SE2). In weave work it is one thread among the
  threads. Arcs built on its covers are thread results: sm:B1550, and sm:B1551, which is held.
