## THE ORDERING PRINCIPLE

Not by interest. By **what a failure teaches**, cheapest-informative first:

1. **BROKEN before BLIND.** A wrong claim actively misleads every downstream reader; a missing one
   merely waits. *(Ladder rule 4.)*
2. **HOLE before frontier.** A gap inside something we already claim is worth more than a new
   region, because it is load-bearing for things already banked.
3. **Ledger before probe** for anything BLIND. B950 is the template: write what the field
   *specifies* before asking what the object supplies. Probing a BLIND rung without its
   specification is how "the object doesn't supply X" gets said unearned.
4. **A rung may not skip OPEN.** BLIND → OPEN → BOUNDED. Something must be *computed* before an
   edge is claimed.

   row citing arc + the missing statement verbatim;

   never restore from memory);
6. a band is DONE when its debt rows are either restored or explicitly declined with a reason.

## STOP RULES — binding

1. **A cell that cannot state its quantifier does not run.** (P0)
2. **A criterion that cannot fail is not a test.** Run the vacuity/base-rate control **before**
   reading the result, not after. B986 died on exactly this — ~70% of *random* polynomials passed
   its test — and cc3's selector reading died the same way at 60.8%.
3. **Propose and refute in the same file.** If a cell produces an attractive reading its own control
   kills, both halves are banked together, so no later seat can re-register the first half.
4. **No rung is marked closed on plausibility.** Quote the closing sentence and its path.
5. **A closure whose scope sentence names a manifold is suspect by construction.**
