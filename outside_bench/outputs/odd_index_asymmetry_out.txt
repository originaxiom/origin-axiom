O3 — THE CONTROL, AND THE TWO WRONG VERSIONS BEFORE IT:
  (i)  RANDOM BULK two-site flips on a reversal-closed pair.
       MIS-SPECIFIED: the Fibonacci defect is at sites {0,1} — AT THE
       BOUNDARY, where edge states live.  Position-matched flips give
       asymmetry 3-5 while deep-bulk flips give 0-1, so position is the
       dominant factor and a bulk control understates the null badly.
  (ii) POSITION-matched flips on RANDOM WORDS.
       VACUOUS: a random binary word has NO spectral gaps, so the gap
       clause selects nothing and BOTH counts are 0.  Verified: edge
       count on a random word = 0.  Comparing against systems with no
       edge states at all is no control.
  (iii) THE VALID CONTROL — OTHER STURMIAN SLOPES at the SAME N with the
       SAME two-site boundary defect: comparable gap structure, same
       geometry, only the slope's arithmetic differs.
