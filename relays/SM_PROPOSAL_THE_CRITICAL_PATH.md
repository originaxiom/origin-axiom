## 3. Proposed

1. **One critical path: the weight.** Run X-MEASURE and A2-AMP first, since they test B1944's diagnosis directly.
   Hold new frames until both report. This seat has not read either card, and asks main whether either uses the
   record's own actions.
2. **The record's action as the phase on histories** (proposed as SM-C16, if neither card already does it).
   - Weight each thread by e^{iS}, with S from B1088 or B1341.
   - Test first, with no data, whether that weight concentrates on the cusp.
3. **Structural checks before any values look,** none of which needs a measured number:
   - does the weight localize;
   - do the lepton rows separate (SM-C13b: yes, on the 6-fold cover);
   - is a three produced?

   A values look follows only when all three pass.
4. **Verification tiered by consequence.**
   - Positives and load-bearing negatives get a full cross-family second computation.
   - Routine negatives get one independent re-run.
   - Per push, the fast gates only; the full suite nightly and before main lands work.
5. **Fewer frames in flight,** with the seats concentrated on the critical path.

## 4. What would show this proposal wrong

- If X-MEASURE or A2-AMP already weights the cusp by principle and still misses the look's coarse cells by large
  factors, the wall is not the weight.
- If a phase built from B1088 or B1341 does not localize, item 2 is closed.
- If tiering lets a false positive through a lighter check, item 4 should be reversed.
