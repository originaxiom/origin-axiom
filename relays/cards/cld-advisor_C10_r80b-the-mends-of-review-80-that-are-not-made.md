## 3. How it could come out wrong, written before any run

1. **A mend needs a sentence of the mathematics that main's files do not give.** The level at the web seat's W8,
   the quotient at W9, the precision at the SM seat's 26, the reading at 24. Where main's table, its kept output or
   the arc's own verdict line gives the words, those words are used. Where none does, the row is sent back with
   what was found, and is not built.
2. **Seventeen findings were checked by nobody but their reader.** This seat makes each again before it mends it.
   If one does not hold here, it is not mended: it goes back with the output. A patch for one of the seventeen says
   that main has not checked it. Nothing is written as checked by main that the table does not give as checked.
3. **A row's remedy is not given.** The 68 tests that read nothing outside themselves are "registered as a debt"
   and the table says no more. What is built for a row like this is the least that holds it: a count that can only
   fall, the tests held by name. Whether a test of the 68 should read something else is a judgement of what it is
   about, and is main's.
4. **Four of the nine asserts stand in other sessions' files.** They are not touched. Of main's five, two fail
   with the constant taken out: what the line should state is the mathematics, and is main's unless the script's
   own comment gives it.
5. **A file to mend is sealed, or named in a list of hashes.** A sealed file is not changed. A list of hashes is
   made again by its own tool, and the patch says so; where that cannot be done, the row stops.
6. **A lock is slow.** B1861's long lock and B1895's run for a long time on this machine. Each is run once on the
   patch, and the note gives the time. A lock that could not be run is said to be not run.
7. **A dated note trips another instrument.** The old words kept in a note are the words the retraction sweep and
   the tripwires look for. Each patch is run against the sweep, and a note is written so that the old words stand
   with their word of mention.
8. **The plan's page is built by a script from a source.** The mend is made in the source, and the page is built
   again. The sentence that is replaced is the owner's: it is printed nowhere, in no output, no message and no
   note of this seat. What replaces it is main's label, which the page already has.
9. **The foundation's version 1.67 is written by a script of main's that holds the passages it replaces.** The
   script is run and its output is the foundation. Nothing it prints is copied anywhere. The arc and the lock are
   built in the form of B1891, the version before.
10. **The base moves.** If main lands R80a, series 4 or the move with a change, the parts are built again on its
    head, and the note says which patches changed.
11. **A test of main's is changed.** Only with a dated note in the test, as at every series.
