## 3. How it could come out wrong, written before any run

1. **Seven of these rows main has not checked beyond the principal case, and the sub-cases it has not made.** Each
   is made again before it is mended. One that does not hold here goes back with the output.
2. **The reader's own cases are in a file read through a mask.** What is built is from main's words alone. Where
   main's one line does not say what the case is (row 51's two directions, row 47's set of files), the case this
   seat makes is said to be its own reading of the line.
3. **Row A can turn honest pages red.** A banned phrase that today hides behind a mark may stand on main. What
   stands is measured first; each is named to main, and held by name only with its record.
4. **Row A changes what is walked.** The framing gate walks the disk today; a gate is a function of the commit. In a
   tree that is no checkout (a test's small tree) it still walks the disk, as the arrival gate does.
5. **Row C changes how a registry row is read,** and 13 names are held in the sweep's tables. A row that was read
   as a reading and is now swept can turn a page red: measured first, as series 5 did for its rows J and L.
6. **Row H is a table of 68 names.** By series 5's rule a table of what is held by name grows only by a recorded
   act; the table is new, and stands whole in the commit that makes it.
7. **Main's second probe is an output with no script.** Its cases are written again from its lines; if a case of
   this seat's gives another answer than main's kept line, it is said.
