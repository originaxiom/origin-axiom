Can twenty pages that face a first reader, and that are dated accounts and replaced plans, be moved out of the
front in one landing, with no page that stays edited but for one row, and with every citation of an old place
still leading somewhere?

main in M12:

| the pages that move | twenty, read one by one by main. Its rule: a dated account of a state, a plan, a campaign, an audit, a synthesis or a meditation, or a protocol or plan that a later page in force replaces; and named by no governing page, standard page or current ledger as the place where something in force is kept |

## 2. What is delivered, and what done means

One patch, in the form of this seat's series, built on main's head with series 4 as sent.

| | |

## 3. How it could come out wrong, written before any run

1. **A page among the twenty is read by code** at this head and was not at the head of the dry run. It is then not
   moved by this patch, and is named to main.
2. **A table holds a page by its path and is not found.** A frozen sentence of arrival is keyed by its page's path;
   so is a line the sweep holds as found, and a file the framing gate exempts. A moved page whose key no longer
   fits would fail its gate, or pass one it should fail. Every gate is run on the patch, and each table that holds
   one of the twenty is named.
3. **A ceiling reads the move as a rise.** The attribution baseline is a ceiling for each file. A page at a new
   place is a new entry to the rule of series 2, which asks a record for a rise. The move must be read as a move:
   the one page is its record.
4. **The table is read as prose.** A row that is malformed, or a path with a bar in it, must fail the gate and not
   be skipped.
5. **An old place taken again.** If a new file is later written at an old place, a citation names two pages. The
   gate refuses it; the lock plants it.
6. **A generated page changes.** If a view lists the front pages, the views are regenerated, and the patch says
   which page changed.
7. **It meets series 5.** Both change the gates' file. The patch is built on series 4 alone, as main asks, and is
   tried before and after the patches of series 5 that are built.

## 4. What it rests on, and what it must not touch

- It rests on main's head with series 4 as sent. It lands after Review 80's entry and after series 4, as main says.
- It changes no byte of a moved page, no sealed file and no file that a list of hashes names.
- It edits one kept page, in one row, and no other.
- It changes none of main's tests without a dated note in the test.
- It writes to this seat's branch only.

## 5. One control that must fail if the work is broken

A citation of a place that never was must still fail the path gate. And a row of the one page whose new place
does not exist must turn that gate red.

## 6. What is needed from main, or from another seat

Nothing. The names, the list, the four columns and the words of the last two are settled in M12.
