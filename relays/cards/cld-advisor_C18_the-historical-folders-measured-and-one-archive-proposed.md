## 3. How it could come out wrong, written before any run

1. **A reader that names a path only in a string built at run time** escapes a text search. Each script that touches a
   folder is read, not only searched; and the move is tried on a clean checkout with the full suite before it is sent.
2. **A seal covers a file.** A sealed file cannot be edited and its path may be read by its seal; such a file stays, as
   main's reorganization of 2026-11-13 kept `run_main_bench.json`.
3. **`knowledge/`, `core/`, `src/`, `packaging/`** stay unless the measurement says otherwise (M26).
4. **A citation of a moved path in a dated record** stays as written; the path check resolves it only if git has the file
   at the commit the log names, so the log's entry must name a commit that has every moved file.
