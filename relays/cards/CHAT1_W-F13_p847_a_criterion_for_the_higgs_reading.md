## The question

M24: S = a_i·i + a_j·j + a_k·k, built holomorphically in τ; S̃ = εS*εᵀ with ε = j, which equals a_i*·i + a_j*·j + a_k*·k.
- Both repeat along a thread, and their limits differ.
- The fibre mirror does not exchange them.
- The frame defines the Higgs's hypercharge but never uses it.

Is there a criterion that picks one?

## The candidates to examine

1. **The algebra.** Is S̃ the conjugate doublet of S, in the sense of iσ₂H*, and so of opposite hypercharge?
2. **Hypercharge.** In the Standard Model's Yukawa terms both H and H̃ appear. Hypercharge neutrality fixes which one
   couples to which right-handed sector. So the criterion would turn on which sector the frame reads.
3. **Analyticity** (B1927's own principle for the end): S is holomorphic in τ; S̃ is not.
4. **W-F9's order.** Conjugation exchanges a module with its conjugate, as duality exchanges V with V*. Is P-847's bit
   W-F9's order bit in another form?
