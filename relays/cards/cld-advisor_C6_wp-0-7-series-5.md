## 3. How it could come out wrong, written before any run

1. **Row A reads a form of English.** An honest sentence whose denial stands two clauses back would be refused. A
   boast whose own clause holds a denial about something else would pass. The four sentences excused on main today
   must each read the same after the mend, or be held by key as found; the twin set is built from them.
2. **Row A is main's wording joined with this seat's.** The stem that lets "aimless" excuse came from this seat's own
   mend of 2026-11-11. The rule of excuse is main's to settle before it is built (§ 6).
3. **Row B moves a day.** Three commits after the root have another day in UTC than in their own zone. A debt's age
   may then differ by one day from what a page of main says. The patch must say which sentences move.
4. **Rows B and E meet whatever stands on a side line on the day they land.** Today there is none. If one stands by
   then and breaks the rule, it is held by name as found.
5. **Row I opens a file to read it.** A compressed file can be large, and the gate must not be slowed past use: the
   one that stands is read once. A file made to expand without end must fail and not hang.
6. **Row D turns a pass into a skip** in a clone that holds main alone. That is what the runner's rule asks, and a
   fresh clone then prints one gate as not run. Main may want it to fail instead.
7. **Row F changes how the runner prints.** Every gate's passing sentence is read for the words that print a skip
   before the rule is changed, so that no gate that read nothing starts to print PASS.
8. **Row H changes what a record names.** A record names an entry today. Two rises of one entry are two steps, and
   each needs its record. Main's lock for B1893 asserts that the case still passes: the mend turns that test red at
   the first assertion of each pair, as its own note says it will, and main changes it with its page.
9. **It is a fifth layer.** Eighteen patches of this seat stand unlanded. A patch sent back below rebuilds this one.
