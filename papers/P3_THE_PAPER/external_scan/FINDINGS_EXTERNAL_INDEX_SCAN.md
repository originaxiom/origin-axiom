# EXTERNAL SCAN — is `I = t0 - r1` ever non-zero on domain D? (2026-09-10)

An independent attack on the question B1297 §5.1 leaves open and L202 gates:

> "(c) **Whether `I != 0` occurs at all** on a one-cusped hyperbolic manifold in domain D: no example
> found; a general vanishing theorem is NOT proved, and if one exists the index is not an instrument."

Independent bench: own Fox calculus over **F_p** (not Q(zeta_12)), own cocycle/coboundary linear algebra,
SnapPy 3.3.2 only for presentations and peripheral words. Nothing taken from the record.

## Result

**9 108 sectors inside domain D. Every one returns `I = 0`. Zero exceptions.**

| | |
|---|---|
| manifolds | 98 one-cusped census manifolds (**not** m004 or its tower) |
| primes | 7, 13, 19 |
| local systems | `Sym^1 rho ⊗ psi` and `Sym^2 rho ⊗ psi` — the PREREG family |
| twists | order-3 cusp-trivial characters (the Galois-unprotected case) |
| sectors in D | **9 108**, all `I = 0` |

For scale: B1324 found **two** unprotected sectors in the whole m004 tower. This is ~4 orders of
magnitude more evidence, on manifolds the programme has never touched.

## Why the search moved off m004

`A = H_1(M)/<mu, lambda>` is exactly the group of cusp-trivial characters. Scanning the one-cusped
census: **203 123 manifolds, of which 22 211 admit order-3 cusp-trivial characters.** The obstruction
that makes m004's tower nearly sector-free (torsion generated by the meridian) is not generic. The
non-vacuity question is not a question about m004, and should never have been searched there.

## The sharpening: non-vanishing happens exactly where D excludes it

An unfiltered scan finds `I = ±1` in **roughly two thirds** of all sectors. Every one has **non-reductive**
`rho`. Restricting to reductive kills all of them.

Note `a0 = a0*` is a **proxy** for reductive, not equivalent — a reducible-indecomposable `rho` can
satisfy it, and an early pass of this scan was wrong for exactly that reason. The correct filter:
since `rho(mu)` is unipotent and non-trivial, no completely-reducible `rho` qualifies, so

> **reductive + parabolic cusp ⇒ `rho` irreducible**

and conversely every irreducible `rho` with parabolic cusp satisfied both domain conditions
automatically (0 sectors fell outside D once irreducibility was imposed). **D is self-enforcing here.**

## The theorem to prove, in a recognisable form

From the record's own identity `F = (a0 - a0*) + r1 - t0`, with `a0 = a0*` on D:

> **`I = 0`  <=>  `h^1(M;V) = h^1(M;V*)`.**

So the missing vanishing theorem is exactly: *for a reductive local system with parabolic cusp holonomy
on a one-cusped hyperbolic 3-manifold, the twisted first Betti numbers of `V` and its dual agree.* That
is a statable, literature-shaped question, not an open-ended search. Duality gives only
`r1 + r1* = t1` (the two images are mutual annihilators, forcing the **sum**); equality of the two
is the extra content.

## What this does and does not establish

- **Does not** prove the vanishing theorem. It is evidence, not proof.
- Is computed **mod p**, not in characteristic 0. This cuts the right way: rank can only *drop* mod p,
  and a drop in `r1` would *raise* `I`, so the method is biased toward *detecting* non-vanishing.
  Nine thousand zeros is therefore meaningful, not vacuous.
- Controls that passed on every sector: `t0 = t0*`, `t1 = t0 + t0*`, `r1 + r1* = t1`. A bench that
  failed these would be reporting nothing.

## Consequence for the programme

The named next computation — the 54 multi-cusped chiral covers — is now **the lower-value branch**. It
varies the cover, and the evidence says the cover is not what controls the answer. The higher-value
branch is the **vanishing proof** in the form above. If it goes through, the chirality row closes as a
proved boundary rather than an open search — a ledger upgrade of the same kind as `lambda` being
external-by-theorem, and it would retire L202 rather than extend it.
