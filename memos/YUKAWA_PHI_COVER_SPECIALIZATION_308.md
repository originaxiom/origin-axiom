# R030 — the height-308 Phi cover lifts by proper specialization

## Verdict

The four principal opens `D(Phi_1)`, `D(Phi_3)`, `D(Phi_5)` and `D(Phi_9)`
already cover the characteristic-zero height-308 hypersurface.  An explicit
characteristic-zero Bezout expression is not needed to prove this coverage
statement.

The proof is not the invalid inference “unit ideal modulo one prime implies
unit ideal over `Q`.”  That inference fails on affine families whose generic
points can escape to infinity.  Here the simultaneous base locus is a closed
subscheme of a **proper toric model**.  Properness turns the exact empty
`GF(1009)` special fiber into an empty generic base locus.

R030 pays coverage and existence only.  It does not emit a characteristic-zero
contracting homotopy for the 432-to-36 cover refinement, evaluate the normalized
residue trace, or construct either Serre tail.  Those remain the load-bearing
parts of the down/lepton evaluator.

## Exact computational input

Let

```text
A = Z[zeta_12],
Z_A = (dP6 x dP6)_A,
Y_A = V(f) subset Z_A.
```

The norm hypersurface `f` and the selected height-308 map coefficients are
integral in the power basis `(1,zeta,zeta^2,zeta^3)`.  For every one of the 36
deterministic toric charts, the payload stores those exact integral generators
and a literal identity over the prime

```text
p = (1009, zeta_12-r),    ord(r)=12,

1 = u_f f + u_1 Phi_1 + u_3 Phi_3 + u_5 Phi_5 + u_9 Phi_9
    in GF(1009)[y1,y2,y3,y4].
```

The dependency-free certificate reconstructs every integral generator from a
source-locked serialization of the height-308 `Phi` vector, the norm-section
coefficients and the toric frame algorithm; it then reduces the generators,
multiplies the sparse polynomials, and checks equality coefficient by
coefficient.  A planted multiplier perturbation fails on every chart.  The
generator and compressed-payload hashes are also pinned, so a different
modular problem cannot silently pass under the same verdict.

R028 proves independently that these are exactly the 36 affine charts of the
proper toric model, with the required line-bundle frames.  R030 checks all 36
rather than using equivariance because the subset `(1,3,5,9)` is not
`C12`-stable.  Hence the common zero scheme of these **same four global
components** is empty in the selected special fiber.

## Proper-image proof

Define the global four-component base locus

```text
B_J = V_Y(Phi_1,Phi_3,Phi_5,Phi_9) subset Y_A.
```

It is closed in `Y_A`, while `Y_A` is closed in the projective toric scheme
`Z_A`.  Therefore

```text
B_J -> Spec(A)
```

is proper.  Suppose its generic fiber `B_(J,K)`, for `K=Q(zeta_12)`, were
nonempty.  Then the image of `B_J` would contain the generic point of the integral scheme
`Spec(A)`.  A proper morphism is closed, so that image would contain the closure
of the generic point, namely all of `Spec(A)`.  In particular it would contain
the prime above `1009`.  The exact modular identities prove that fiber is
empty, a contradiction.  Thus

```text
B_(J,K) = empty.
```

Consequently those four opens cover `Y_K`; a fortiori the twelve-component
`Phi:G_Y -> O_Y(H)` is pointwise surjective.  On every characteristic-zero
affine chart the ideal generated by `f` and these four local components is
therefore the unit ideal existentially (Nullstellensatz plus faithful scalar
extension).  What is not supplied is a small explicit set of
characteristic-zero multipliers realizing that identity.

No flatness assumption is used.  Properness is exactly the missing hypothesis
that blocks the ordinary “a point escaped through a denominator” counterexample.

## What changes in the evaluator

The old open statement mixed two different obligations:

1. **Does the principal-open refinement really cover in characteristic zero?**
   R030 closes this positively, with four rather than twelve component opens
   per toric chart.
2. **Can a fine-cover cocycle be collapsed explicitly into R027's normalized
   36-chart trace model?**  Still open.  This needs either an explicit
   characteristic-zero Bezout/contracting homotopy or a direct toric-residue
   evaluator that bypasses the collapse.

The exact 18 connecting entries, the 9+6 mixed tail entries, the 3 tail/tail
entries, and the surviving line in the down-Higgs `P3` therefore remain
unevaluated.
