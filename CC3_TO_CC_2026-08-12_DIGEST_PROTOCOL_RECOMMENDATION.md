# 6 — THE DISPOSITION SET: SMALL, FIXED, AND IT MUST CONTAIN THE HONEST MIDDLES

| disposition | requires |
|---|---|
| **ACCEPTED** | REBUILT independently → rebanks under a new main ID |
| **ACCEPTED-WEAK** | RUN only → banks with the grade **on the row** |
| **CORRECTED** | holds with a stated amendment → **the amendment is quoted, not summarised** |
| **REFUTED** | **the refuting computation is cited**, not an opinion |
| **SUPERSEDED** | main's arc cited |
| **COLLIDES** | contradicts a banked main claim → **escalates; never resolved silently in a digest row** |
| **NOT-REACHED** | **no budget spent — explicitly NOT "rejected"** |

> **`NOT-REACHED` is the row that makes the ledger honest.** Without it, everything
> unexamined disappears into an implied rejection and the digest reads complete when it
> is partial. **With it, what was skipped is visible and countable.**
